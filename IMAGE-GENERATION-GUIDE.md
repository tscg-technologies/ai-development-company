## 4. Instructions for Replacing Placeholders with Generated Images

When your image files are generated from Google Flow:

1. **Verify Dimensions & Filenames:**
   - Ensure the generated images match the exact filenames listed in the inventory table (e.g., `hero-neural-matrix-core.jpg`).
   - Save or place all generated images into an `assets/images/` directory or directly in root/images.

2. **Update the HTML Markup:**
   - Locate each `.img-placeholder` element in the respective HTML file.
   - Replace the placeholder `<div>` with standard responsive image markup:
   ```html
   <!-- Before (Placeholder) -->
   <div class="img-placeholder aspect-4-3">
     <span class="placeholder-badge">IMAGE PLACEHOLDER #5</span>
     <span class="placeholder-filename">service-ai-agent-autonomous.jpg</span>
     ...
   </div>

   <!-- After (Production Image) -->
   <img 
     src="assets/images/service-ai-agent-autonomous.jpg" 
     alt="Autonomous AI Agent Architecture with Tool Calling Nodes" 
     class="aspect-4-3" 
     style="width: 100%; object-fit: cover; border-radius: var(--radius-md); border: 1px solid var(--border-medium);"
     loading="lazy"
   >
   ```

3. **Aspect Ratio Preservation:**
   - The CSS classes `.aspect-21-9`, `.aspect-16-9`, and `.aspect-4-3` already exist in `css/styles.css`. Applying them directly to the `<img>` tags guarantees zero layout shift (CLS) during page loading.
